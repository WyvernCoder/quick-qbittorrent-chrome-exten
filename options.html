连接你的 qBittorrent

设置一次，之后在扩展弹窗里粘贴磁力链接即可开始下载。扩展不会修改下载路径、分类、限速或暂停状态，所有下载配置都由 qBittorrent 自己决定。

01

WebUI 连接

HTTP / HTTPS

填 qBittorrent 的完整访问地址，可带反向代理子路径，例如 https://example.com/qbt。不要填 /api/v2。

保存时 Chrome 会请求访问上面这个地址的权限。扩展只会连接你填写的 qBittorrent， 不会读取其他网站。首次使用需要允许，否则无法发送任务。

打开 WebUI
02

工作方式

简单、透明，不接管你的下载规则。

  1. 1
    登录

    每次操作先通过 qBittorrent WebUI API 登录，结束后立即退出会话。

  2. 2
    提交磁力

    只发送磁力链接到 /api/v2/torrents/add，不携带覆盖参数。

  3. 3
    按默认下载

    保存路径、分类、标签、限速、暂停等全部沿用 qBittorrent 当前默认设置。

账号密码保存在本机 Chrome 的 chrome.storage.local 中，不会同步到云端， 也不会发送给 qBittorrent 以外的服务。
